# Personal photographs stay off this host

The production build does not publish this directory. Keep private pictures in native Photos/Contacts. Imported private profiles currently require `photo:null`; the familiar labels and initials remain available. Public icon PNGs at the repository root are unchanged.

Do not add personal photographs here. The public-source gate rejects image assets in this directory. Git ignore rules, noindex, obscure filenames and a private source repository do not protect files delivered by a public website.
